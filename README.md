# Real-Time Co-Shopping Platform (Textile Focus)

This project aims to build a real-time co-shopping experience for textile products, allowing multiple users to browse products together, see each other’s interactions, chat, and manage a shared cart in real time.

## 🎯 Project Vision
Online shopping is often a solo experience. This platform transforms it into a social activity by enabling:
- Real-time product viewing synchronization (soft sync)
- Shared cart with per-user item tracking
- Live chat and presence indicators
- Textile-focused product browsing

## 🧱 Tech Stack (Planned)
- Backend: Java Spring Boot, REST API, WebSocket
- Frontend: React
- Real-time: WebSocket (STOMP)
- Data Source (MVP): Public product APIs (later: custom textile dataset)

## 🚀 MVP Scope
- Product listing & detail view  
- Real-time “friend is viewing this product” notifications  
- Soft synchronization (opt-in co-view)  
- Shared cart (who added what)  
- Live chat within shopping room
